# Gunjan Singh Portfolio

Responsive personal portfolio built using HTML5 and CSS3 only.

## Design Features
- Indigo, violet, lavender and icy-blue theme
- Split hero section
- Glass-style cards
- Education timeline plus table
- Circular skills layout
- Project card gallery
- Contact form
- Flexbox and CSS Grid
- Hover effects, transitions and animation
- Responsive media queries
